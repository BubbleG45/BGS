# Sports Roadmap

*Full list of sports BGS should eventually support. Not sequenced/prioritized — see [BUILD_PLAN.md](BUILD_PLAN.md) for the currently committed launch sports (volleyball indoor, then soccer/kickball-style). Scoring-model tags are a rough guide for future data-model planning, not a commitment.*

## Core team sports

- Basketball — *period-based, running score*
- Softball — *inning-based*
- Baseball — *inning-based*
- Soccer (incl. indoor soccer, futsal) — *running score*
- Flag football — *period-based, running score*
- Football (general/tackle leagues) — *period-based, running score*
- Ultimate (frisbee) — *running score / point cap*
- Lacrosse — *period-based, running score*
- Field hockey — *period-based, running score*
- Ice hockey — *period-based, running score*
- Floor hockey — *period-based, running score*
- Dek hockey — *period-based, running score*
- Broomball — *period-based, running score*
- Bubble soccer — *running score*

## Volleyball variants

- Volleyball (indoor) — *set-based, best-of-N* (launch sport)
- Sand/beach volleyball — *set-based, best-of-N*
- Grass volleyball — *set-based, best-of-N*

## "Social sports" staples

- Kickball — *inning-based* (sport #2, per BUILD_PLAN.md)
- Dodgeball — *elimination/round-based*
- Cornhole — *point-cap, individual/pairs*
- Bocce — *point-cap*
- Bowling — *frame-based, individual score*
- Wiffle ball — *inning-based*
- Skeeball — *point total, individual score*
- Spikeball — *rally scoring, set-based*
- T-ball — *inning-based*

## Racquet/precision sports

- Pickleball — *set-based, best-of-N*
- Tennis — *set-based, best-of-N*
- Golf — *stroke/hole-based, individual score*
- Darts — *leg/set-based*
- Curling — *end-based (like innings)*
